# 세이버자동조회

Sabre Red Web(`srw.sabre.com`)에서 실시간 `WPNCB` 왕복 최저가 기본운임(`KRW`)을 백그라운드로 수집해 날짜별 엑셀(`.xlsx`)로 저장하는 Windows 자동화 프로그램입니다.

## 핵심 특징

- **실시간 운임 수집 (운임 DB 불필요)**: `I → 1{출국} → (1*) → 01{클래스} → 1{귀국} → (1*) → 01{클래스} → WPNCB` 순서로 Sabre가 계산한 실제 기본운임(`KRW`)을 직접 추출합니다.
- **내부 API 고속 엔진 + CDP 자동 폴백**: Chrome `9223` 디버그 세션(`항공자동조회`의 `9222` 포트와 분리)에서 첫 `I` 명령으로 `NGV://POS/SEND` 요청 템플릿을 브라우저 메모리에만 캡처해 인페이지 `fetch()`로 직결 실행합니다. API 호출이 실패하거나 미지원 환경이면 자동으로 CDP UI 입력 모드로 전환합니다.
- **백그라운드 무간섭 실행**: 조회 시 브라우저 창을 최소화해도 마우스·키보드 포커스를 뺏지 않고 백그라운드로 동작합니다.
- **조기 마감 및 오류 재조회**: 가용 화면에서 `Y` 이하 이코노미 좌석이 전석 마감(`0/L/C`)이면 세그를 잡지 않고 즉시 `예약마감`으로 처리하며, 전체 기간 종료 후 `조회오류` 날짜만 1회 재조회합니다.
- **노선그룹 2단 관리**: 로컬 JSON(`sabre-routes.json`)에 노선그룹(`routeGroup`)과 노선별 여러 항공일수(`+2, +3, +4` 등)를 저장하고, GUI에서 노선그룹·세부 일수별로 체크해 연속 실행합니다.
- **세션 만료 자동 복구**: 조회 중 세션이 만료되면 그 시점까지 수집분을 엑셀에 저장한 뒤 자동 재로그인(Okta 푸시 미승인 시 5분 간격 최대 5회 재전송) 후 끊긴 날짜부터 이어서 조회합니다.
- **실측 예외 자동 처리**: Sabre `S02 Error` 모달(`.s02-modal`)은 `Next → Finish`로 자동 해제하고, API 응답의 `d.atk` 토큰 회전 및 HTTP `401` 인증 만료를 즉시 감지해 복구합니다.

## 폴더 구성

| 파일 | 역할 |
| --- | --- |
| `세이버자동조회_실행.vbs` | 검은 CMD 창 없이 GUI 실행 (권장) |

| `sabre_terminal.py` | Chrome 9223 CDP 연결, 자동 로그인, 내부 API(`NGV://POS/SEND`) 및 조회 엔진 |
| `sabre_core.py` | 날짜 변환, 가용/세그/`WPNCB` 파싱, 엑셀 저장·재개방 검증, 노선 JSON 관리 |
| `sabre-routes.json` | 등록 노선그룹·편명·항공일수(`days`)·조회종료일 설정 |
| `sabre-config.example.json` | 로그인 설정 양식 (실제 계정은 같은 폴더 `sabre-config.json`에 분리 저장) |

| `작업일지.md` | 개발 변경 이력 및 검증 기록 |
| `.gitignore` | `sabre-config.json`, `output/`, 캐시·백업 폴더 커밋 방지 |

## 실행 방법

### 1. 일반 사용자 (GUI)

1. `세이버자동조회_실행.vbs`(또는 `세이버자동조회_실행.bat`)을 더블클릭합니다.
2. `[브라우저 실행/로그인]`을 누르면 로그인 팝업이 열립니다. `Agent ID`, `Password`, `PCC`를 입력하고 `로그인`을 누르면 디버그 Chrome(`9223`)에 연결되어 자동 로그인과 Okta 푸시 전송이 진행됩니다.
3. 팝업에서 `로그인 정보 기억하기`를 체크하면 `sabre-config.json`에 저장되어 2회차부터는 팝업 없이 바로 로그인됩니다(아이디/비밀번호 오류 시 계정 잠금 방지를 위해 저장 기억이 자동 해제됩니다).
4. `자동조회` 탭에서 시작일·종료일과 조회할 노선그룹·항공일수를 체크한 뒤 `[▶ 조회 시작]`을 누릅니다.

### 2. AI 에이전트 / 명령줄 (CLI)

```powershell
# 등록 노선그룹·노선 목록 JSON 조회
python -X utf8 sabre_cli.py --list

# 로그인 및 세션 생존 확인
python -X utf8 sabre_cli.py --login

# 특정 노선그룹 + 항공일수 지정 조회
python -X utf8 sabre_cli.py --group ICN-TAO --days 2,3

# 지역명 + 기간 지정 조회 (충칭 -> 중경 별칭 지원)
python -X utf8 sabre_cli.py --region 중경,칭다오 --start 2026-12-01 --end 2026-12-31

# 사용 중인 전체 노선 일괄 조회
python -X utf8 sabre_cli.py --all
```

## 엑셀 저장 규격

- **저장 경로**: `G:\내 드라이브\안티그래비티\workspace\04. 요금조회\01. 항공\{지역명}\`
- **파일명**: `{YYYYMMDD} 조회_{출발지}{도착지}_{항공사}_플러스{N}.xlsx` (예: `20261120 조회_ICNTAO_KE_플러스2.xlsx`)
- **시트 구성**: A열 `날짜`(`YYYY-MM-DD`), B열 `운임`(정수 KRW / `예약마감` / `조회오류`), C1 `조회기준`(예: `인천/충칭 CA *+ 3 조회기준`).
- **자동 저장 및 검증**: 15일마다 중간 저장, 전체 종료 후 `조회오류`만 1회 재조회, 저장 직후 파일을 다시 열어 날짜 누락·중복과 C1·운임 형식을 검증합니다.

## 제한 사항 및 주의

- 같은 Sabre 계정(`4028`)은 호스트 터미널 회선(LNIATA)을 공유하므로 **반드시 1개 인스턴스만 실행**해야 합니다. `Area A~F` 동시 병렬 실행은 Sabre 호스트가 `PREVIOUS ENTRY ACTIVE`로 차단하고 여정이 섞이므로 금지합니다.
- 세션 만료 시 Okta Verify 푸시 승인은 휴대폰에서 직접 눌러야 합니다.
- 수동 `■ 정지` 후 이어 조회하려면 상단 `시작일`을 마지막 저장 다음 날짜로 맞춰 다시 실행하세요.
